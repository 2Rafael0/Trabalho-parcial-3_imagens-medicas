# Trabalho-parcial-3_imagens-medicas
O trabalho fez uso do banco de dados disponível no Zenodo: https://zenodo.org/records/13274445
O objetivo é classificar as imagens de tumor em maligno ou benigno, usando aprendizado de máquina.

Os modelos usados foram o resnet101 e o densenet121, comparando o desempenho de ambos.

Como o trabalho foi feito no Colab, é necessário alterar os links para a pasta desejada.
